# Translation glossary (Thai → English)

The game is written in Thai first; English sits beside it as `L(thai, english)` (src/i18n.js).
Use these names everywhere so every screen agrees. Tone: terse, old-fashioned dark fantasy
(Dark Souls / Bloodborne item text), second person "you", no modern slang.
