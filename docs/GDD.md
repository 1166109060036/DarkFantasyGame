# MOONMIRE: เอกสารออกแบบเกม (Game Design Document)

## 1. วิสัยทัศน์

> "เดินลุยบึงใต้แสงจันทร์ป่วยไข้ ในโลกที่ดูเหมือนความทรงจำเลือนรางของเกม PS2 ที่เคยเล่นตอนเด็ก"

- **แนว:** Open-world action-adventure มุมมองบุคคลที่หนึ่ง โทน dark fantasy / folk horror อ่อน ๆ
- **แรงบันดาลใจด้านเกมเพลย์:** The Witcher (เควสต์จากชาวบ้าน, ล่าสัตว์ประหลาด, ปรุงยา), Red Dead Redemption (การเดินทางในโลกกว้าง, บรรยากาศ, สภาพอากาศ)
- **แรงบันดาลใจด้านภาพ:** ภาพอ้างอิงจาก @OZAVRY ได้แก่ ซุ้มประตูหินในหุบผาที่มีน้ำเรืองแสง, คางคกแม่มดใต้เห็ดยักษ์กลางสายฝน, รางรถไฟจมน้ำใต้ท้องฟ้าสีฟ้าสว่าง และคนเลี้ยงแกะหัวอีกาตาเรืองแสง
- **ความรู้สึกหลัก:** เหงา ลึกลับ งดงาม อึดอัดเล็กน้อย แต่ไม่ถึงขั้นสยองขวัญ

### เสาหลักของการออกแบบ (Design Pillars)
1. **บรรยากาศมาก่อน:** ทุกระบบต้องเสริมความรู้สึก "คืนฝนตกใต้จันทร์สีฟ้า"
2. **ตัวละครแปลกแต่อบอุ่น:** สัตว์-มนุษย์ (คางคก อีกา) ที่พูดจาเหมือนนิทานพื้นบ้าน
3. **สำรวจด้วยสายตา:** สถานที่สำคัญมองเห็นจากไกล (แสงเรืองของวิหาร, ตะเกียงของยายคางคก, ก้อนหินบนเนิน)
4. **ข้อจำกัดยุค PS2 คือสไตล์:** low-poly, texture เล็ก, หมอกหนา คือสุนทรียะ ไม่ใช่จุดอ่อน

## 2. Art Direction: สูตรภาพ "PS2 แสงจันทร์"

| องค์ประกอบ | กฎ |
|---|---|
| พาเลต | น้ำเงินเข้ม → ฟ้าไฟฟ้า (น้ำ, ฟ้า), เขียวมอส (หิน, หญ้า), สีอุ่นมีน้อยมาก (เหรียญทอง, ตะเกียงคางคก) ใช้เป็นจุดเด่นเท่านั้น |
| แสง | แสงจันทร์ directional สีฟ้า-ขาว + hemisphere ฟ้า/เขียวเข้ม + point light น้อยดวง |
| น้ำ | เรืองแสงเอง (emissive) มีลาย caustic เคลื่อนไหว เป็นแหล่งแสงหลักของฉาก |
| ท้องฟ้า | เมฆเป็นริ้วยาว สว่างรอบดวงจันทร์ มีดาวประปราย ฟ้าแลบเป็นครั้งคราว |
| โมเดล | ตัวละคร 300–2,000 polygons, ต้นไม้เป็นแผ่นใบไขว้ (crossed cards) |
| Texture | 32–128px ใช้ bilinear filtering (PS2 ใช้ bilinear ไม่ใช่ nearest แบบ PS1) |
| Post-process | ความละเอียดต่ำ, bloom, dither, vertex snap เล็กน้อย, vignette, film grain |
| เงา | blob shadow ใต้ตัวละคร ไม่มี real-time shadow |

## 3. โลกของเกม (แผนที่ 640×640 เมตร)

| สถานที่ | คำอธิบาย |
|---|---|
| **บึงแสงจันทร์** (ใต้) | จุดเริ่มเกม รางรถไฟจมน้ำ ต้นไม้ตายห้อยมอส วิญญาณบึงชุกชุม |
| **เนินจันทร์** (ตะวันออก) | ทุ่งหญ้าบนเนิน แกะดำ 20+ ตัว รั้วไม้ผุ วงหินตั้ง บ้านของโกวัก |
| **สถานีร้าง** | ปลายรางรถไฟ ชานชาลาหินและหลังคาพัง |
| **ป่าตะวันตก** | ต้นไม้หนาทึบ เห็ดยักษ์ เห็ดเรืองแสง บ้านของยายคางคก |
| **หุบผา** (เหนือ) | แม่น้ำไหลผ่านช่องเขาแคบ ซุ้มประตูหินโค้ง บันไดหินจมน้ำ |
| **วิหารจมน้ำ** | ลานน้ำเรืองแสงล้อมด้วยหน้าผา วิหารบนฐานหิน รูปปั้นอีกาเฝ้าประตู |
| **ปราสาทแขวนฟ้า** | เกาะหินลอยฟ้าล่ามโซ่ ปราสาทโกธิกสูง 200+ ม. น้ำตก ทะเลสาบ วังวนบนฟ้า (ยังขึ้นไปไม่ได้: ตะขอสำหรับบทที่ 2) |
| **ราชาหินผู้หลับใหล** | หัวยักษ์สวมมงกุฎครึ่งจมดิน มือยักษ์ สะพานหิน กระถางไฟ |
| **ซี่โครงอสูร** | โครงกระดูกยักษ์คร่อมทางรถไฟในบึง |
| **หมู่บ้านสถานีร้าง** | บ้าน 4 หลัง บ่อน้ำ โรงเตี๊ยมเทียนหลอม (มีภายใน) |
| ซากปรักหักพัง | กระจายทั่วแผนที่ เป็นจุดสังเกตสำหรับการสำรวจ |

## 4. ตัวละคร

- **ผู้เล่น (ผู้เดินทาง):** ไม่มีชื่อ ถือดาบเก่ากับ "ตะเกียงจันทรา" ที่ส่องแสงสีฟ้า
- **โกวัก ผู้เลี้ยงแกะ:** มนุษย์หัวอีกา สวมผ้าคลุมมีฮู้ด ตาเรืองแสงสีฟ้า พูดสั้น ห้วน ขึ้นต้นด้วย "กา..."
- **ยายคางคก:** แม่มดคางคกใส่หมวก ผ้าคลุมสีกรมท่าลายแดง นั่งใต้เห็ดยักษ์กอดหม้อทอง ขายยาและต้มน้ำมนต์ พูดว่า "ฮึ่มม..." เรียกผู้เล่นว่า "ไอ้หนู"
- **วิญญาณบึง:** ดวงไฟลอย ไล่ตามผู้เล่นในระยะใกล้ โดนฟัน 2 ครั้งจึงสลาย ดรอปเหรียญ
- **แกะดำ:** ฝูงแกะขนสีเข้มที่เดินกินหญ้าแบบสุ่ม

## 5. ระบบเกม (มีแล้วในเวอร์ชันต้นแบบ)

- เดิน วิ่ง กระโดด ลุยน้ำ (ช้าลงในน้ำลึก) ปีนบันได/ขั้นหิน หน้าผาชันเกินไปปีนไม่ได้
- ต่อสู้ด้วยดาบแบบฟันเป็นวงโค้ง (hit arc) วิญญาณบึงชนแล้วทำดาเมจ พลังชีวิตฟื้นเองเมื่อไม่โดนโจมตี 6 วินาที
- ยาฟื้นพลัง (ซื้อจากยายคางคก 8 เหรียญ) ตายแล้วฟื้นที่ checkpoint (NPC ล่าสุดที่คุยด้วย) และเสียเหรียญ 25%
- เควสต์ 7 ขั้น พร้อมเข็มทิศแบบ Skyrim/Witcher ชี้เป้าหมาย และแผนที่โลก
- บทสนทนาแบบพิมพ์ทีละตัวอักษร มีตัวเลือก ร้านค้า
- สภาพอากาศเป็นวงจร ฝนหนัก/เบา ฟ้าแลบ เสียงฟ้าร้องดีเลย์ตามระยะ
- เสียงสังเคราะห์ทั้งหมด บันทึกอัตโนมัติ รองรับมือถือ
- ดนตรีประกอบ adaptive แต่งสดด้วยโค้ด: กลางคืน / กลางวัน / ใกล้สิ่งก่อสร้างยักษ์ / ต่อสู้ (ความเข้มตามจำนวนศัตรู) / บอส (Dies irae) / โรงเตี๊ยม (จิ๊ก 6/8, ได้ยินอู้อี้จากข้างนอก) และ sting ตอนตาย/ชนะ
- เสียงเอฟเฟกต์ 3 มิติ + reverb ตามสถานที่, เสียงเท้าตามพื้น, เสียงดาบตามวัสดุ, เสียงบรรยากาศตามภูมิภาคและเวลา, ปรับเสียงเพลง/เอฟเฟกต์แยกกัน

### วิถี (Class)
เลือกตอนเริ่มเกม เปลี่ยนได้ที่โรงเตี๊ยม หลักการคือ **แต่ละวิถีต้องเปลี่ยนกติกา ไม่ใช่แค่ตัวเลข** และผูกกับโลก Moonmire:
- **ผู้ตีระฆัง** — ใช้นาฬิกาจังหวะของดนตรี adaptive เป็นกลไกต่อสู้ (rhythm combat) + เสียงสะท้อนเผยศัตรู
- **หมอปลิง** — HP เป็นทั้งพลังชีวิตและทรัพยากร ปลิงเป็น projectile ที่กลับมาเติมเลือด ผูกกับปลิงยักษ์ในบึง
- **สัปเหร่อแบกโลง** — ศพศัตรูเป็นทรัพยากร (4 ช่อง) ให้พลังติดตัว เช่นยืมคำสาปของหญิงร่ำไห้มาใช้กลับ ฝังศพ = จุดเกิดใหม่
- **ผู้แบกไส้เทียน** — HP ละลายตามเวลา ต้องวางแผนเส้นทางตามกองไฟ ซ่อนตัวในความมืด และปักเทียนสร้างเขตปลอดภัยจากร่างซีด

### ระยะที่ 2: ย้ายไป Engine สำหรับเกมเต็ม (ถ้าจะขายบน Steam/มือถือ)
แนะนำ **Godot 4** (ฟรี, เบา, export ได้ทุกแพลตฟอร์ม, มีชุมชนทำ PS1/PS2 shader เยอะ) หรือ **Unity** (ถ้าต้องการ asset store)

เทคนิคทั้งหมดในโปรเจกต์นี้ย้ายได้ตรง ๆ:
- `ps2.js` → post-process shader / SubViewport ความละเอียดต่ำ + `TEXTURE_FILTER_NEAREST`
- vertex snapping → vertex shader ใน material
- crossed-card foliage + wind sway → MultiMeshInstance3D + shader
- น้ำเรืองแสง/ท้องฟ้า → ใช้ GLSL เดิมแทบไม่ต้องแก้ (Godot shading language คล้าย GLSL)

## 7. หลักการออกแบบ Megalophobia

- **ขนาดเทียบคน:** สิ่งก่อสร้างยักษ์สูง 30–100 เท่าของผู้เล่น (หัวราชา 60 ม., ปราสาท 200+ ม.)
- **หมอกแยกชั้น:** ใช้ `fogScale` ใน `ps2ify()` ให้ของยักษ์โดนหมอกน้อยกว่าของทั่วไป จึงเห็นเป็นเงาทะมึนจากระยะ 300+ ม. ขณะที่ต้นไม้และพื้นดินจมหายในหมอก
- **มุมมองจากด้านล่าง:** วางทางเดินให้ผู้เล่นต้องเดินลอดใต้ (รางรถไฟลอดซี่โครง, ทะเลสาบใต้ปราสาท, สะพานไปที่หน้าราชา)
- **ท้องฟ้าใหญ่เกินจริง:** วังวนจักรวาลกว้างราว 70° และดวงจันทร์ยักษ์บนขอบฟ้า
